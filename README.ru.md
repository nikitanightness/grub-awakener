# GRUB Awakener

[🇺🇸English](README.md) | **🇷🇺Русский**

Легковесный сервис, позволяющий включать ПК по сети (Wake-on-LAN) и выбирать нужную ОС для загрузки (в моём сетапе: **Proxmox** или **Windows**) прямо из GRUB.

---

## О проекте

Я часто путешествую, и мне регулярно требуется удаленно запускать домашние серверы. Стандартный Wake-on-LAN включает компьютер, но тот всегда загружается в ОС по умолчанию, если перед физической клавиатурой никто не сидит, чтобы выбрать другую систему в меню GRUB.

Этот сервис решает проблему: он работает в виде легковесного демона на роутере, отправляет «магический» пакет WoL по запросу и передает нужный пункт загрузки в GRUB по HTTP во время старта машины.

### Почему Go?

Изначально я планировал написать бэкенд на Python. Однако, поскольку сервис работает прямо на домашнем роутере (**Keenetic Ultra KN-1811**), мне не хотелось тащить лишний оверхед в виде рантайма Python, виртуальных окружений и зависимостей.

Я выбрал **Golang**, так как он компилируется в один компактный исполняемый бинарник без внешних зависимостей. На самом деле, это был мой первый опыт написания на Go! В целом мне очень понравилось, несмотря на некоторые языковые особенности.

## Как это работает

1. Вы отправляете HTTP POST запрос сервису `grub-awakener` на роутере с указанием целевой ОС.
2. Сервис сохраняет запрошенный `boot_entry_id` (с заданным TTL) и рассылает WoL magic packet.
3. Компьютер включается, и GRUB инициализирует свои сетевые/HTTP модули.
4. GRUB обращается по адресу `http://<ROUTER_IP>:<PORT>/v1/awakening-info?reset=true&format=grub-vars` для считывания и сброса сохраненного состояния.
5. Если запуск произошел через WoL, GRUB устанавливает запрошенную ОС пунктом по умолчанию и сразу же начинает её загрузку.

## Сборка

Скрипт `scripts/build.sh` собирает проект под **Keenetic Ultra KN-1811** (`linux/arm64`):

```bash
chmod +x scripts/build.sh
./scripts/build.sh
```

## Использование

### 1. Запуск на роутере

```bash
./grub-awakener -mac-addr AA:BB:CC:DD:EE:FF -wol-ip-addr 192.168.1.255 -port 9009
```

### 2. Поиск ID пунктов загрузки в GRUB

Чтобы узнать список доступных пунктов меню и их идентификаторы на вашей Linux-машине, запустите скрипт напрямую с GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/nikitanightness/grub-awakener/main/scripts/list-boot-entry-ids.sh | sh
```

Либо запустите локальный скрипт:

```bash
chmod +x scripts/list-boot-entry-ids.sh
./scripts/list-boot-entry-ids.sh
```

> [!NOTE]
> **Пользовательские читаемые ID:**
> Можно вручную отредактировать `/boot/grub/grub.cfg` и назначить простые понятные идентификаторы каждому `menuentry` (например, `--id proxmox` или `--id windows`).
> 
> *Внимание:* Поскольку `/boot/grub/grub.cfg` генерируется автоматически, любые ручные правки в нем будут перезаписаны при следующем выполнении `update-grub` или `grub-mkconfig`.

### 3. Настройка GRUB

#### Быстрая установка (напрямую с GitHub)

Запустите интерактивный установочный скрипт прямо из GitHub:

```bash
curl -fsSL https://raw.githubusercontent.com/nikitanightness/grub-awakener/main/scripts/install-grub-config.sh | sudo sh
```

Либо запустите локальный скрипт:

```bash
sudo ./scripts/install-grub-config.sh
```

Скрипт запросит `awakener_host`, `awakener_port`, запишет конфигурацию в `/etc/grub.d/09_awakener` и предложит автоматически обновить GRUB.

#### Ручная установка

Либо скопируйте [`grub.d/09_awakener`](grub.d/09_awakener) в `/etc/grub.d/09_awakener`, укажите IP и порт вашего роутера внутри файла, сделайте его исполняемым и обновите GRUB:

```bash
sudo chmod +x /etc/grub.d/09_awakener
sudo update-grub
```

### 4. Важно: Настройка Dual-Boot с Windows (для работы WoL)

> [!IMPORTANT]
> При использовании дуал-бута с Windows **обязательно** настройте параметры электропитания сетевого адаптера в Windows. Иначе после выключения ПК из Windows сетевая карта полностью обесточится, и Wake-on-LAN перестанет работать до следующей ручной загрузки.
>
> 1. Откройте **Диспетчер устройств** (`devmgmt.msc`) в Windows.
> 2. Разверните ветку **Сетевые адаптеры**, кликните правой кнопкой мыши по вашему Ethernet-адаптеру и выберите **Свойства**.
> 3. Перейдите на вкладку **Управление электропитанием** (Power Management) и убедитесь, что включены **все три галочки**:
>    - [x] **Разрешить отключение этого устройства для экономии энергии** *(Allow the computer to turn off this device to save power)*
>    - [x] **Разрешить этому устройству выводить компьютер из ждущего режима** *(Allow this device to wake the computer)*
>    - [x] **Разрешать вывод компьютера из ждущего режима только с помощью "магического" пакета** *(Only allow a magic packet to wake the computer)*
> 4. Перейдите на вкладку **Дополнительно** (Advanced) и убедитесь, что параметр **Wake on Magic Packet** установлен в **Enabled** (Включено).
> 5. *(Рекомендуется)* Отключите **Быстрый запуск** (Fast Startup) в Windows (*Панель управления -> Электропитание -> Действие кнопок питания*), так как гибридный сон может препятствовать сохранению режима ожидания сетевой карты для WoL.

### 5. Пробуждение через `curl`

* **Загрузка в Proxmox:**
  ```bash
  curl -X POST http://192.168.1.1:9009/v1/wake-up \
       -H "Content-Type: application/json" \
       -d '{"boot_entry_id": "proxmox"}'
  ```

* **Загрузка в Windows:**
  ```bash
  curl -X POST http://192.168.1.1:9009/v1/wake-up \
       -H "Content-Type: application/json" \
       -d '{"boot_entry_id": "windows"}'
  ```

* **Загрузка ОС по умолчанию:**
  ```bash
  curl -X POST http://192.168.1.1:9009/v1/wake-up
  ```
